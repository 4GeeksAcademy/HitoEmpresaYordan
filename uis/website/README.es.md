# Website de Nexova

Aplicación pública independiente construida con Next.js App Router. La portada presenta las tres líneas de servicio de Nexova; la calculadora es orientativa y no envía ni almacena datos.

Desde esta carpeta:

```bash
npm install
npm run dev
```

El servidor de desarrollo abre `http://localhost:3000`. Comprobaciones disponibles: `npm run lint` y `npm run build`.
